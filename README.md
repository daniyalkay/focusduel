# Focus Duel

Соревнование «кто больше работает за компьютером» на основе [ActivityWatch](https://activitywatch.net).

- `focusduel.py` — программа для Mac (только стандартная библиотека Python). Считает время работы локально и показывает дашборд на `localhost:5700`.
- `index.html` — страница дуэли: открывается по ссылке с кодом группы, в том числе с телефона.

Наружу уходят только цифры по дням: часы работы, отвлечений и отдыха, фокус-блок, переключения, время начала и конца дня. Названия программ, сайтов и окон остаются на компьютере.
